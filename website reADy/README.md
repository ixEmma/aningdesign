# READY-TO-USE WEBSITE KIT

Start here:
1. Read `docs/AGENT_BUILD_BRIEF.md`.
2. Read `docs/ASSET_MANIFEST.md`.
3. Copy the `assets` folder into the website project's preferred static/public assets location.
4. Build the new product sales page with the existing site design system.
5. Do not generate new marketing imagery: use the included mockups and preview pages.
6. The checkout price/URL are intentionally not invented. Use real project values when available.

The teaser PDF is included at the root for direct upload/linking.
